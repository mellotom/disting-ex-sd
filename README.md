# disting-ex-sd

travelers guide for navigating the drum archive: a live, searchable database of the drum kits on my expert sleepers disting ex sd card, built for the **sd 6 triggers** algorithm.

live page: https://mellotom.github.io/disting-ex-sd/

- 12 kits (one flat top-level folder per genre), 4,941 one-shots curated from splice packs
- every file is .wav, 44.1 khz, 16-bit, one-shot
- file names carry a category prefix so each sound family stays contiguous on the sample parameter:
  `1_kick` · `2_snare` · `3_hat_cl` · `4_hat_op` · `5_perc_1` (claps) · `6_perc_2` (toms, wood, shakers) · `7_crash` · `8_impact` (noise bursts, chimes, whooshes)
- `data.json` holds the full index: folder, sample parameter value, category, file, source pack, genre, length

reference: disting ex user manual 1.5 (sd 6 triggers p.40–42, wav naming conventions p.68).

design homage to the house of x / powers of x data pages by tom muller with jonathan hickman. not affiliated with expert sleepers, splice or marvel. samples are not included in this repo.
