03

on the module

dsx_03 · manual 1.5 p.40–42, 68
[ folder ]0–999. chooses the folder the six voices load from. the display shows the folder name while it's current.
[ sample 1–6 ]−1–999. the file for each voice; −1 disables the voice. use the sample # column below.
[ in 1–6 ]gate in n triggers voice n. velocity sensitive: 5v = full velocity.
[ output 1–6 ]1–4 single out · 5 = outs 1/2 stereo · 6 = outs 3/4 stereo.
[ choke 1–6 ]group 1–3: a trigger cuts the other voices in its group. put hat_cl + hat_op together.
midinotes 48–53 (c3–f3) trigger voices 1–6. can be disabled in the algorithm menu.
[ env time ]100 = infinite (plays to the end). lower values add a release, handy for long crashes and impacts.
wav defaultsone-shot, not looping. a playlist can override.
naming tags_V1 velocity layers, _RR1 round robins, _C3 note names. names here use hyphens only, so nothing groups by accident.
es-5first 6 outs fire an end-of-sample trigger per voice.
